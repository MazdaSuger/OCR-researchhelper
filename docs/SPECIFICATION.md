# 史料テキスト分析統合ソフトウェア — 機能詳細仕様書

**プロジェクト仮称:** Shiryō-Coder（史料コーダー）／ HistoryQDA

QualCoder の操作感をベースに、日英混在・縦横書き・大規模史料コーパスに対応した
研究室共有型デスクトップアプリの全体像をまとめる。

---

## 1. 全体アーキテクチャ

| 層 | 採用技術（推奨） | 理由 |
| --- | --- | --- |
| GUI フレームワーク | PySide6（Qt 6 / LGPL v3） | 商用配布も視野に入る場合のライセンス自由度。大規模アプリでの実績豊富。 |
| 言語 | Python 3.11+ | NLP・OCR エコシステムの厚さ |
| ローカル DB | SQLite + FTS5（全文検索） | 数百万字でも軽量・高速。`tokenize=trigram` で日本語対応 |
| 共有層 | PostgreSQL 同期オプション（研究室サーバ）または Git LFS 連携 | 数人〜十数人の共同編集に対応 |
| ファイル実体 | `.md`（YAML Front Matter 付き）＋画像 | Obsidian 互換、Git 管理しやすい |
| プロジェクト形式 | `.shiryo`（zip）／ REFI-QDA `.qdpx` 互換エクスポート | REFI-QDA 仕様 |

## 2. データモデル（コア概念）

```
Project ─┬─ Document (.md + 元画像)
         │    ├─ Segment (文字オフセット範囲)
         │    │    ├─ Code (階層タグ)
         │    │    ├─ Memo (注釈)
         │    │    └─ Sentiment (極性値)
         │    └─ Metadata (YAML: 著者/年代/出典/言語)
         ├─ CodeBook (コードツリー、定義、色)
         ├─ Coder (研究者アカウント、色割当)
         └─ Relations (コード間関係、共起ログ)
```

**Segment は「文字オフセット start/end + コーダー ID + コード ID」** で持つことで、
重複コード・部分重なり・複数コーダーが同じ箇所をコーディングする状況に対応する。

> 実装対応: 本リポジトリの [`shiryo_coder/db/schema.sql`](../shiryo_coder/db/schema.sql)
> および [`shiryo_coder/db/models.py`](../shiryo_coder/db/models.py) を参照。

## 3. 機能モジュール詳細

### 3.1 OCR 取り込みモジュール

両エンジン切替可能設計: UI 上でドキュメント単位または一括設定でエンジンを選択。

| エンジン | 用途 | 縦書き | 英語 | 手書き |
| --- | --- | :---: | :---: | :---: |
| NDLOCR-Lite v1.2（ローカル） | 近世以前〜近代日本語、CPU 動作可、プライバシー優先 | ◎ | △ | ○（v1.2 強化） |
| Tesseract 5（ローカル） | 英語史料、現代横書き日本語、PSM 5 で縦書き対応 | ○ | ◎ | × |
| Google Cloud Vision（API） | 高精度バックアップ、判読困難ページ | ◎ | ◎ | ◎ |
| Gemini / Claude Vision（API） | レイアウト解析＋翻刻補助、くずし字 | ◎ | ◎ | ○ |

**取り込みワークフロー:**

1. **入力:** 画像（jpg/png/tiff）、PDF（複数頁自動分割）、ZIP フォルダ一括
2. **前処理:** 傾き補正・二値化・ノイズ除去（OpenCV）。プレビュー画面で個別調整可能
3. **言語/方向自動判定:** 先頭ページを縮小推論 →「日本語縦書き」「英語横書き」等を提示、ユーザー確認後一括処理
4. **OCR 実行:** バックグラウンドキュー（QThreadPool）でバッチ処理、進捗バー
5. **手動校正画面:** 左ペインに元画像（クリックで対応行ハイライト）、右ペインに認識テキスト。バウンディングボックス↔テキスト相互ジャンプで校正効率化
6. **`.md` 保存:** YAML Front Matter に `language`, `era`, `source_image`, `ocr_engine`, `confidence` を自動付与

```markdown
---
title: 大政奉還上表文
author: 徳川慶喜
year: 1867
era: 江戸後期
language: ja
script: vertical
source_image: ./images/taisei_001.jpg
ocr_engine: NDLOCR-Lite-1.2
confidence: 0.94
---
# 本文
朕惟フニ我皇祖皇宗國ヲ肇ムルコト宏遠ニ……
```

### 3.2 `.md` ライブラリ管理モジュール

QualCoder の File 一覧を拡張し、史料カタログとして機能:

- **三カラムレイアウト:** 左＝フォルダツリー／中央＝ドキュメント一覧（メタデータ列ソート可）／右＝プレビュー
- **メタデータフィルタ:** 年代スライダー、著者、史料群、言語、コード付与状況
- **FTS5 全文検索:** 日本語は trigram、英語は unicode61 トークナイザを言語別に切替
- **タグ・コレクション:** ドキュメントを横断グルーピング（「江戸後期書簡集」など）
- **Zotero 連携:** Better BibTeX の JSON 出力を取り込み、メタデータ自動補完
- **Obsidian 互換モード:** プロジェクトフォルダをそのまま Obsidian Vault として開ける（`[[wikilink]]` 保持）

### 3.3 コーディングモジュール（中核機能）

**コードブック（左ペイン）**

- **無制限階層ツリー:** ドラッグ&ドロップで親子関係変更
- **色割当:** HSL 自動配色＋手動上書き、コーダー別×コード別の二重配色モード
- **コード定義:** 各コードに説明文・包含/除外基準・代表例セグメントへのリンク
- **インポート:** QualCoder / MAXQDA / NVivo のコードブック XML 読込

**コーディング画面（中央ペイン）**

- マウス範囲選択 → 右クリック or キーボードショートカットでコード付与
- **重複・部分重なり許容:** 1 文字に対して任意数のコードを重ねられる
- **可視化モード切替:** 下線色分け（複数コードは積層表示）／左マージンのカラーバンド（QualCoder 方式）／ハイライト塗りつぶし
- **コーダー切替:** 自分以外のコーダーの付与を半透明表示でレビュー可能
- **キーボード駆動:** 頻用コードに数字キー 1〜9 を割当、選択中テキストに即時付与
- **AI 支援コーディング（オプション）:** 類似セグメント検索（文埋め込み→既存コードの代表セグメントとコサイン類似度）→候補提示、ユーザー承認制

**メモ・注釈**

- **3 階層:** プロジェクトメモ／ドキュメントメモ／セグメントメモ
- Markdown 編集、画像・他セグメントへの内部リンク
- **ジャーナル機能:** 日付付きの分析ログ、後から検索可能

### 3.4 センチメント分析モジュール（辞書ベース）

| 辞書 | 言語 | 範囲 |
| --- | --- | --- |
| 東北大 日本語評価極性辞書（用言・名詞編） | 日 | 約 13,000 語 |
| 高村「単語感情極性対応表」 | 日 | 約 55,000 語、-1〜+1 の連続値 |
| ASARI / oseti 互換辞書 | 日 | 否定表現の反転処理込み |
| VADER / SentiWordNet | 英 | 英語史料用 |
| カスタム史料辞書（プロジェクト内拡張） | 日英 | UI で語彙＋極性値追加、共有可能 |

**処理機能:**

- **形態素解析:** 日本語は MeCab（IPAdic-NEologd）／ Sudachi、英語は spaCy
- **史料語彙対応:** 旧字旧仮名→新字新仮名の正規化マップを内蔵、ユーザー追加可
- **分析単位:** 文・段落・コードセグメント・文書全体から選択
- **可視化:** 時系列極性プロット（年代メタデータ使用）、コード別の極性分布ボックスプロット
- **辞書編集 UI:**「我が君」「不忠」など史料特有語に独自値を割当、辞書はプロジェクトに同梱

### 3.5 信頼性検証モジュール（複数コーダー一致率）

- **Cohen's κ:** 2 コーダー間
- **Fleiss' κ / Krippendorff's α:** 3 名以上
- **算出単位選択:** 文字単位／文単位／セグメント単位（一致判定の粒度）
- **不一致セグメント抽出ビュー:** 争点のあるセグメントを並べて表示→協議用エクスポート
- **コーダー研修モード:** マスターコーディング済み文書を「答え」として隠し、新規コーダーの一致率を逐次フィードバック

### 3.6 共起・関係性可視化モジュール

- **共起マトリクス:** コード A×コード B、同一セグメント／同一段落／距離 N 文字以内を選択
- **ネットワーク図:** NetworkX + PyVis（HTML エクスポート可）、ノード径＝出現頻度、エッジ太さ＝共起回数
- **コード関係の手動定義:**「対立」「包含」「因果」など意味的関係をエッジに付与
- **ヒートマップ:** 年代×コード、著者×コード、感情極性×コード
- **時系列分析:** 年代メタデータに基づくコード出現頻度推移

### 3.7 共同作業モジュール

| 方式 | 適用シーン |
| --- | --- |
| A. ローカル+同期サーバ（推奨） | 各 PC にローカル DB、研究室 PostgreSQL へ差分同期。オフライン作業可、コンフリクト解決 UI あり |
| B. ファイル共有方式 | プロジェクトフォルダを Git / Nextcloud で共有、`.md` はテキスト差分でマージ可能 |
| C. ロック方式 | 同時編集を排他制御、シンプル運用 |

- **コーダーアカウント管理:** 役割（管理者／コーダー／閲覧者）
- **変更履歴:** 誰がいつどのセグメントにどのコードを付けたか全ログ保持
- **承認ワークフロー:**「下書きコード」→「主任承認」→「確定」の三段階

### 3.8 エクスポート・連携モジュール

| 出力 | 内容 |
| --- | --- |
| CSV / Excel | コード集計表、セグメント一覧、メタデータ表、感情極性スコア |
| REFI-QDA `.qdpx` | MAXQDA / NVivo / ATLAS.ti / QualCoder との完全互換 |
| 可視化 PNG/SVG | 共起ネットワーク、ヒートマップ、時系列プロット |
| 学術引用形式 | セグメント引用文を APA / Chicago / SIST02（人文系日本）で自動生成、出典メタデータから書誌情報組立 |
| Zotero 連携 | Zotero API で文献追加・引用キー取得 |
| Obsidian Vault | コード=タグ、セグメント=callout、関係性=リンクで再構築 |
| HTML レポート | コード階層・代表例・統計をまとめた静的サイト生成（Jekyll/Hugo 風） |
